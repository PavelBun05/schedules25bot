# 🏫 Школьный бот расписания

Telegram-бот для поиска расписания уроков в школе. Позволяет быстро находить расписание по классам, учителям и кабинетам.

## ✨ Возможности

- 🔍 **Поиск по классу** — введите номер класса (5А, 10Е, 8 Б)
- 👨‍🏫 **Поиск по учителю** — полная фамилия учителя
- 🔎 **Поиск по части фамилии** — находит всех учителей и показывает их расписание
- 🏫 **Поиск по кабинету** — полный номер кабинета (164, 243)
- 📊 **Список всех классов** — команда `/classes`
- 📈 **Статистика** — команда `/stats`
- 🔄 **Обновление данных** — команда `/update`
